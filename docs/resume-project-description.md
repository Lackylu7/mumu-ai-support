# 简历与面试表述

## 项目名称

木木机器人｜企业知识库智能客服与人工协同系统

## 简历版描述

- 负责设计并实现基于钉钉 Stream 与 AI 表格知识库的企业智能客服机器人，完成消息接入、意图识别、业务域路由、实时检索、证据引用和结构化回复闭环。
- 设计“证据优先”回答链路：将知识记录标准化为 Evidence，增加发布状态、版本、适用条件、冲突检测和高风险人工确认门禁，降低模型幻觉对业务制度的影响。
- 实现人工案件协同流程，支持证据不足/冲突/高风险问题自动建案、通知人工负责人、答疑群协作、案件状态流转和结果回流知识审核。
- 完善运行工程：增加断线重连、超时重试、幂等、会话并发控制、心跳、Windows 任务计划程序守护和运行状态监控。
- 建立知识运营能力，支持知识导入、审核、候选门禁、缺口记录、解释层迁移和版本兼容；通过离线 fake gateway/fake model 测试核心逻辑，避免测试依赖线上服务。

## 面试时可以展开的技术点

### 为什么不让模型直接回答？

企业制度问题的错误成本高。系统先检索已发布证据，再让模型负责组织语言；没有证据时转人工，从架构上限制“凭空编制度”。

### 如何处理知识更新？

知识记录带来源、版本和审核状态。机器人只消费已发布内容；新内容先进入候选或待审核状态，人工确认后才进入回答路径。

### 如何处理外部服务不稳定？

用接口隔离 Stream、AI 表格和模型调用，增加超时、有限重试、心跳和断线重连；业务回答失败时进入人工兜底，不把重试无限扩大成重复消息。

### 如何保护隐私？

凭据只从环境变量读取，公开仓库不放真实知识库、日志、数据库、用户 ID 或交付包；发布前做敏感扫描，真实部署使用最小权限和独立密钥。
