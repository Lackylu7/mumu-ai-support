# 安全与隐私边界

## 公开仓库中明确排除的内容

- API key、client secret、access token、refresh token、私钥和 Cookie；
- 钉钉企业标识、真实用户 ID、机器人编码和真实工作空间 ID；
- 企业制度原文、内部知识库导出、聊天记录、数据库、运行缓存和日志；
- 真实人员姓名、企业名称、门店名称和内部群信息；
- 交付 ZIP、备份目录、导入源文件和临时审计材料。

## 代码层控制

1. 配置通过环境变量读取，不在源码中写入密钥。
2. `.gitignore` 默认排除 `.env`、运行目录、数据库、日志和压缩包。
3. 知识检索和答案生成分离，模型不能绕过证据门禁制造制度结论。
4. 授权用户通过 allowlist 限制；人工流程使用独立的负责人 ID。
5. 日志与回答内容分开，避免调试日志无意记录完整用户问题或内部原文。
6. 发布前执行文本敏感信息扫描和安全审计。

## 部署前检查清单

- [ ] `.env` 没有被 Git 跟踪；
- [ ] Git 历史中没有误提交过的密钥；
- [ ] 真实知识库只授予机器人读取所需的最小范围；
- [ ] 生产日志设置脱敏、访问控制和过期清理；
- [ ] 对退款、资格、金额、权限等高风险回答启用人工确认；
- [ ] 发生泄露时立即撤销凭据并轮换，而不是只删除文件。

## 公开版本的诚实边界

本公开版本展示工程方法和可运行代码，不提供真实业务知识，也不承诺对任何企业制度直接可用。部署到真实组织前，必须重新完成数据授权、隐私评审、模型供应商评估和业务验收。
