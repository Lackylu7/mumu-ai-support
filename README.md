# 木木机器人｜证据优先的企业知识库客服系统

木木机器人是一个面向钉钉工作场景的企业知识库客服系统。它把实时知识检索、结构化业务路由、LLM 解释、证据引用、失败兜底和人工转接串成一条可观测的服务链路。

本仓库是可公开展示的脱敏版本：代码、架构和合成测试数据保留；真实企业知识库、运行状态、凭据、人员信息、内部文档和交付压缩包不进入仓库。它适合用于技术作品集、面试讲解和本地二次开发。

## 项目亮点

- 证据优先回答：模型只能基于本次检索到的知识证据作答，避免把模型常识伪装成企业制度。
- 多级检索：先做意图与业务域路由，再执行全表快照/实时检索、主题过滤、批量审阅和证据拼装。
- 结构化输出：统一返回答案、依据、来源、置信度、是否需要人工确认等字段，方便钉钉卡片和审计。
- 人工闭环：当证据不足、存在冲突或业务风险较高时，自动生成案件、通知人工负责人并停止继续猜测。
- 运行可靠性：包含幂等、重试、超时、心跳、运行状态、会话记忆和并发控制等工程化能力。
- 可演进知识库：支持知识条目导入、审核、候选答案、缺口记录、解释层和版本迁移。
- 安全边界：敏感配置只从环境变量读取；公开版默认不携带知识内容、缓存、日志、数据库和账号信息。

      │                              │

## 快速开始

```powershell
py -3.11 -m venv .venv
.\\.venv\\Scripts\\python.exe -m pip install -e ".[test]"
Copy-Item .env.example .env
```

填写本地 `.env` 后，可运行：

```powershell
.\\.venv\\Scripts\\python.exe -m pytest -q
.\\.venv\\Scripts\\python.exe -m mumu_bot.cli --help
.\\.venv\\Scripts\\python.exe -m mumu_kb.cli --help
```

没有钉钉凭据时仍可运行单元测试和离线逻辑；真实 Stream 连接需要自行配置钉钉应用、机器人和授权知识库。
