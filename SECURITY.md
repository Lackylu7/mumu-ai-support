# Security Policy

## Scope

This public repository is a sanitized reference implementation. It intentionally does not include production credentials, private knowledge, real user identifiers, runtime state, logs, databases, or internal source documents.

## Reporting

Please do not open a public issue containing secrets, personal data, or private business content. If you find a security problem in this repository, contact the repository owner privately and include the affected file, impact, and a minimal reproduction.

## Deployment reminder

Rotate any credential that may have been exposed. Removing a secret from the working tree is not enough if it has entered Git history or a build artifact.
